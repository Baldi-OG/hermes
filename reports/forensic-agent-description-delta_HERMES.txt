METRICS.
Briefly describe the effectiveness metrics you use (e.g., accuracy) and how they are computed (e.g., the model outputs a binary prediction, which is stored in a database and evaluated using a Python script). Note that reporting actual evaluation scores is essential for comparing the quality of different approaches.
~~~~~~~~~~~~~~~~~~~~
Response time:
- The time it takes for a model to respond to a prompt, measured in seconds.

Accuracy:
- The percentage of correct predictions made by the model, calculated as (number of correct predictions / total number of predictions) * 100.
- Binary classification with additional "unknown" class for cases where the model is not confident enough to make a prediction.

Amount of retries:
- The models don't always provide an answer in the correct format
- Max retries is 2. Therefore, this metrics is in the range of 0-2

Confusion matrix:
- Computed by tracking ground truth labels and model predictions.
